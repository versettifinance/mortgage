# GetMeMortgage.ca

A mortgage brokerage web app built for Versetti Finance ("Get Me Mortgage" - brand promise: Own It Easy), live at getmemortgage.ca (also getmemoney.ca).

## Overview
A lead-generation and self-serve calculator platform for Ontario homebuyers, designed to help prospective borrowers understand affordability and costs before speaking with a broker.

## Features
- Ontario-accurate mortgage calculators:
  - Affordability calculator with stress test
  - Payment calculator with CMHC insurance tiers
  - Closing cost estimator
- Lead capture and scheduling via Calendly integration
- Contact form powered by Formspree
- Analytics via GA4

## Stack
- Static site (HTML/CSS/JS)
- Hosted on Netlify
- Formspree (forms), Calendly (booking), GA4 (analytics)

## Status
Actively used as the live site for Versetti Finance's mortgage brokerage business (FSRA licensing in progress).
